================================================================================
TROUBLESHOOTING
================================================================================

Problema: "Connection refused" en backend
Solucion:
  1. AURORA no accesible (esperado fuera de red corporativa)
  2. Frontend igual funciona (visuals grises)
  3. Sigue los pasos OPCION B

Problema: Visuals todos grises dentro de red corporativa
Solucion:
  1. Ejecuta: python verify_datasources.py
  2. Verifica que AURORA muestre [OK]
  3. Revisa logs backend: grep "\[eyeon" backend.log
  4. Check: ¿tabla VArticulosFichaTecnica existe? ¿tiene datos?

Problema: Frontend no carga en http://localhost:5173
Solucion:
  1. Revisa que `npm run dev` haya iniciado sin errores
  2. Verifica puerto 5173 no esté ocupado: netstat -an | grep 5173
  3. Limpia node_modules: rm -rf frontend/node_modules && npm install

Problema: "Forbidden" en login
Solucion:
  1. Verifica email: fmorenob@auroracorp.es (minúsculas)
  2. Contraseña debe ser la del ERP Aurora
  3. SCHAIN_ALLOWED_EMAILS en backend/.env
  4. Verifica en AURORA_AUTH_API_URL si usuario existe
